# Kasanki Labs Scoop bucket

[Scoop](https://scoop.sh) manifests for [Helium Solo](https://helium-solo.pages.dev) by Kasanki Labs.

```powershell
scoop bucket add kasanki https://github.com/Kasanki-Labs/scoop-bucket
scoop install kasanki/helium-solo
```

This installs the `helium` command-line program, also available as `helium-solo`. `scoop update helium-solo` gets new versions.
